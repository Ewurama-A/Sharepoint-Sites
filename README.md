# Spotless SharePoint Portal

Internal SharePoint site created for Spotless Cleaning Services to support communication, onboarding, document sharing, and team collaboration.

## Overview

This project involved designing and organizing a SharePoint-based company portal using Microsoft SharePoint Online templates and customization tools. The site was structured to provide employees and management with centralized access to company resources, announcements, and operational documents.

## Features

- Company homepage with branded design
- Staff onboarding resources
- Shared document libraries
- Internal announcements and updates
- Organized navigation for easier access to company materials
- Permission-based access management
- Mobile-friendly SharePoint layouts
- Integrated Microsoft 365 tools

## Tools & Technologies

- Microsoft SharePoint Online
- Microsoft 365
- SharePoint Templates
- Microsoft Teams
- PowerPoint
- Microsoft Lists
- Stock Images & Media Assets

## Responsibilities

- Customized SharePoint templates to fit company branding
- Managed site permissions and user access levels
- Organized document libraries and navigation structure
- Added and configured company resources and pages
- Selected and integrated visual assets and stock images
- Assisted users with access and onboarding support
- Maintained consistency across site pages and layouts

## Outcome

The SharePoint portal improved internal organization by centralizing company resources and simplifying access to important documents and updates. It also supported smoother onboarding and communication workflows for staff members.
